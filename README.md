# INFINITE DIMENSIONS – Atari ST demo (browser)
A browser recreation of an Atari ST demo by Infinite Dimensions, cut on the beats and bars of the track. It renders at 320x200 with 16 colours per scanline from the STE 4096-colour palette, and the borders are opened. It syncs to audio.currentTime, and the scroller messages reshuffle on every play.
Font: Press Start 2P (SIL OFL).
