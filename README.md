# MYSTICALG – Atari ST demo (browser)
A browser recreation of an Atari ST demo, synced to the beats of mysticalg's track. It renders at 320x200 with 16 colours per scanline from the STE's 4096-colour palette, and the borders are opened. The scroller messages are reshuffled on every playback.
Font: Press Start 2P (SIL OFL).
